# Agents instead of lanes (done 2026-09-25)

Lanes were a model with parallel slots plus automatic lanes for every other model; the Work tab showed "0/13" for the
two lanes the user had set up, chats picked a model while subagents picked a lane. The user's idea: the things you set
up are **agents**, and chats and subagents both run on them. Kept for reference: the settings are in
`docs/SETTINGS.md` (Agents), the RPCs in `docs/PROTOCOL.md`, the tools in `docs/TOOLS.md` (Agents), the UI in
`docs/UI.md`.

## Decisions with the user (2026-09-25)

- **An agent is a named worker on one model with a number of instances.** Two agents on the local `qwen3.8-27b` map to
  its two slots; a third agent on a cloud model is a third instance. No temporary agents: to use a model you set up an
  agent on it (the picker has "New agent…").
- **An agent is active only while its model is loaded.** Only one inference engine runs on the GPU at a time (nInfer or
  llama.cpp, switched in AiSwitcher). An agent that made AiProxy load another model would unload the one the other
  agents run on, so NetPI never loads a model; the agents follow what is loaded.
- **Agents can be switched off by hand**, in the agent's dialog and from the Work tab.
- **Profiles stay separate:** the agent is where a chat runs, the profile who it is (its "soul").
- **Subagents pick a free agent** (`agent_choices`, `agent_spawn { agent }`); the owner still chooses their tools.
- **The Work tab always shows the agents** with their states.

## As built

- **Contracts (additive):** `ILaneScheduler.ResolvePool(model, agent)` and `ChooseAgent(model, agent)` (default
  methods); `LanePoolInfo.Available` / `Unavailable` / `Disabled`; `LaneUnavailableException`; `SessionAgent`
  (`meta.agent`); `SpawnRequest.Agent`.
- **Host:** the model catalog lists again every `models.refreshSeconds` (10; the providers answer from their own
  caches), so a model loaded or unloaded reaches `models.changed` within seconds; a provider that keeps failing is logged
  once. New installs start with an agent for the default model.
- **Lanes plugin ("Agents"):**
  - the scheduler's pools are the agents (`agents.<id> = { model, instances, use, disabled, cost, budget }`);
  - an agent's availability: not disabled; a local model `loaded`; a cloud provider not offline;
  - agents on one local model share its slots (the catalog's concurrency);
  - a run refused at once on an inactive agent, and waiters told when their agent goes inactive;
  - model calls without an agent get a slot per model while they run;
  - `lanes.changed` only when something the Work tab shows changed;
  - the upgrade turns `lanes.<id>` into agents (plus one for the default model) once;
  - `agents.use`, `agents.setEnabled`; `agent_choices` and the "# Agents" prompt section replace `lanes_list` and
    "# Lanes"; the ledger bills a call to the chat's agent (its daily cap).
- **Agent plugin:** a run takes its chat's agent (`meta.agent`) or the scheduler's choice on its model and keeps it; an
  inactive agent or a model no agent runs ends the run with a notice; subagents start on an agent (`meta.agent`).
  Compaction on the chat's own model reuses the run's slot (a second slot on a shared local model could wait forever).
- **UI:**
  - the composer's agent picker (state, busy/instances, price; "New agent…", "Manage agents"), `/agent`;
  - Settings → Agents & budget (rows, the agent dialog with name, on/off, model, instances, the shared-slots warning, the
    note, price and cap); the runtime settings page is now "Runs";
  - the Work tab's Agents section (every agent, its state, an on/off switch, who runs and waits) and "Runs";
  - `input.np-switch` in the kit; `ctx.app.openSettings(page)` for plugin tabs.

## Results

Unit suites: Providers 41 (330 checks), Tools 54, Agent 84 (agents listed with their states, the shared model slots,
chats on agents, the upgrade, instances following the catalog, `agent_choices` / `agent_spawn { agent }`), Aux 100,
Host 38. E2E 56 / 716 checks (agents set up live: a chat on one, switched off, a stopped backend, a model no agent runs).
UI mock e2e 185 (the picker, "New agent…", the Work tab switch, the settings rows and dialog, renaming).
